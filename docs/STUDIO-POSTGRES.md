# Studio PostgreSQL 与持久队列

2026-09-28。本批交付是可选的 PostgreSQL 存储和独立任务进程；未迁移共享数据库，未发布公网。原文件模式保留。

## 启动顺序

要求 Node.js 24+、PostgreSQL 数据库。通过私密服务环境注入 `STUDIO_AGENT_DATABASE_URL`；连接串按数据库要求启用 TLS，不写进仓库或前端。先用隔离数据库演练。

```sh
npm run build:studio-agent
npm run db:migrate
npm run db:verify
npm run studio:service
```

另一个进程使用同一个数据库环境，并配置 `ARK_API_KEY`：

```sh
npm run studio:worker
```

独立部署可分别运行 `dist-studio-agent/server.mjs`、`pg-worker.mjs`；显式迁移用 `node dist-studio-agent/pg-migrate.mjs migrate`。保留同目录的 `worker-child.mjs`。API 无须模型密钥，Worker 必须有。API 启动只验证结构，不自动建表。

`STUDIO_AGENT_PORT` 默认 5198，`STUDIO_AGENT_STATE_DIR` 指向私密目录，保存匿名会话签名与独占锁。API 仍限回环地址与本机同源访问。Vite 使用 `STUDIO_AGENT_URL=http://127.0.0.1:5198` 代理；未设置数据库环境的独立服务仍用原 JSON 模式。Vite 内嵌模式仍用 JSON，数据库模式请走独立服务代理。

## 数据和任务语义

- 独立 `studio_agent` schema。项目源码、不可变历史和幂等回执在同一行事务提交，保留 20 版本上限。
- 每个匿名身份最多 100 条任务；API 关闭保留排队任务，Worker 领取后执行。浏览器识别“排队中”。
- 多个 Worker 共享数据库领取锁，全局同时最多一个有效运行租约；租约 60 秒，心跳约 1 秒。取消或失租终止本地执行，迟到结果无法提交；取消时继续占用租约，执行退出后才释放，期间不能清理该记录。
- Worker 优雅退出把活跃任务标为 interrupted；强制退出后，下次领取会清理过期租约。中断任务不自动重跑，避免不明确的重复模型调用。排队任务可继续执行。外部模型请求的计费无法由数据库保证严格只发生一次。
- 排队/执行期间数据库保存完整请求（包含选区所属源码和用户指令）；完成、失败、取消、中断时清空请求 payload。候选仍包含用于校验的源码，直到用户清理任务。已经确认的任务被清理后，可从项目回执恢复原确认结果。数据库、备份均需按私密作品数据管理。
- 健康检查包含当前数据库连通性；它不代表 Worker 在线或模型服务可用。

## 切换与回滚边界

原 JSON 数据不会自动进入 PostgreSQL。切换数据库相当于选择另一套后端数据，不能把旧项目“找不到”当成丢失，也不能自动重建覆盖。现已提供离线显式导入、归属核验与备份恢复工具，步骤见 [数据迁移说明](STUDIO-DATA-MIGRATION.md)；尚未对现有数据执行切换。

匿名 Cookie 和签名目录必须保留；它们不是跨设备账号。仍不支持多个 API 实例共享同一个本机状态目录，不可据此声称已完成生产多实例身份体系。

`npm run db:rollback-empty` 仅删除空的 Studio schema；有项目、任务或额外对象时拒绝，整个操作回滚。已有数据可用归档恢复到新的空数据库，不能原库覆盖或合并，详见数据迁移说明。

## 验证范围

自动化测试使用临时目录中的真实 PostgreSQL 18 和随机测试数据库；不连接用户共享库。覆盖事务、并发、归属、版本冲突、幂等、任务租约/取消、API 重启恢复和显式迁移回滚。测试数据库及进程结束后清理。最终全量 74 文件、571 项测试通过；独立 API/Worker 真实 Ark 生成、确认及重复确认闭环通过。
