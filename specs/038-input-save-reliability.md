# Spec038 — 输入与保存可靠性第一批

## 执行计划

1. 复现输入法组合输入未结束时收到保存/导出 flush 的行为。
2. 长文与演示预览均拒绝此时提交，提示用户先确认或取消候选，再重试；不排队自动保存。
3. 长文的源码修改失败时取消当前保存/导出回调，避免随后 flushed 消息把旧源码当作最新内容交付。
4. 完整回归、构建，再走真实报告导入、修改、保存、下载和文件选择器再导入。

## 复现证据

新增两个桥接事件测试在修复前均失败：compositionstart → candidate → flush 会发送候选文本的 edit 和 flushed。修复后该阶段只返回 flush-blocked；compositionend 后重试才允许 edit/ended/flushed。
