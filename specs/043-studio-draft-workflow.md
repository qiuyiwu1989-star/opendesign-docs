# 043 Studio 结构草稿与局部修改（第一阶段已发布）

## 范围

免费、本机优先的多任务创作草稿原型。明确显示尚未接入 AI，不把固定结构编排称为模型生成。

- 文档库入口按需打开 Studio；填写主题、受众、目标、材料摘要。
- 整理与人工确认 2–12 页大纲，创建自包含 HTML 结构草稿。
- 选择单处文字，显示原文/修改后，确认才追加版本；取消不生成版本。
- 提案绑定版本 ID、完整基线源码和原文；过期提案拒绝应用。
- 恢复历史版本追加新版本，不删除旧版本；最多 20 版。
- 独立 IndexedDB `opendesign-studio/tasks` 保存多个任务；同一读写事务比较 revision 后追加保存，冲突拒绝覆盖并保留输入。
- 旧 localStorage 草稿迁移为 `legacy-v1`，保留原始数据；并发迁移只产生一个任务。
- JSON 备份包含需求、大纲、已应用版本；恢复创建新任务，限制 5 MiB。备份生成后修改需求/大纲会使下载链接失效，避免下载旧快照。
- 未保存输入退出/切换使用页内确认；未确认文字必须确认或取消后才能切换位置、恢复版本或转入 Docs。
- 转入 Docs 创建新副本，后续不回写已有 Docs 手工内容。
