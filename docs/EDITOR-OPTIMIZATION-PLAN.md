下一阶段的可执行顺序与依赖以 [2026-09-19 工作计划](NEXT-WORK-PLAN.md) 为准；下文保留详细验收标准与历史记录。

更新：2026-09-18。本轮交付 MCP 页面入口；以下是下一阶段的实施顺序，未完成项不作为已上线功能。按验收门推进，不承诺未经核实的工期。

## 产品目标

把来源 HTML 稳定地变成可编辑、可审阅、可再次交付的作品。Library 提供案例，设计总监给出判断，Studio 负责对话创作，Docs 负责精修与交付。接入已开放，编辑器优先提高真实完成率。

## 推荐的三个实施批次

### 第一批：先做到放心改、放心交付

P0/1 + P0/2。先复现输入/保存边界，再针对失败修复；补完原生中文输入、立即保存和刷新、深脑真实来源、下载重导入验收。交付一份可复现的验收报告和已验证样本，不先重写编辑器。

### 第二批：把编辑手感和资源质量做好

依次做 P1/3 → P1/4 → P1/5。Moveable/Selecto 当前仅为实验候选，真实手势验收通过前不迁移生产。用一份教育课程、一份企业提案、一份分析报告做固定走查样本；每批只解决确定问题。

### 第三批：加入协作与 AI 能力

P2/6 → P2/7。云端身份、权限、保留和撤销规则先于分享；Studio 的 AI 修改需要基线版本和明确范围。开发者账号/额度属于 Connect 的另一条工作，不阻塞本地编辑体验修复。

## 发布标准

- 有具体用户问题、实现范围、回滚点和实际浏览器证据。
- 保存、刷新、下载及再导入根据改动范围验证，不能只用测试数量或 HTTP 200 宣称完成。
- 原始 HTML 用精确源码片段修改，保留版式和可逆版本；不擅自执行导入脚本或覆盖原文。
- 每批完成后更新 TASKS、ACCEPTANCE；未通过项单独列出，不与已通过项混报。

## 当前已完成与未完成边界

已完成：公开 SDK/MCP/REST、来源确认、代表样本编辑保存刷新和实际下载、临时副本清理/过期/限流。MCP 页面入口为本轮新增。

尚未完成：深脑真实生产按钮最终验收；部分物理拖拽/触屏/原生 IME 检查；完整字体与资源兼容矩阵；账号云协作和 Studio AI 局部修改。对应历史细项保留在 TASKS.md，以上为面向产品的优先级重排。
