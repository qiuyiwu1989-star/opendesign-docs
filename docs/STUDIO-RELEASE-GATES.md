## A1：当前候选真实作品往返

**当前状态：部分已有记录；真实下载往返未验。**

企业提案和课程分别创建一份合成样本，执行：

1. 记录当前 Studio 任务、初始版本和目标文字；旁边页面保留一段唯一标记。
2. 提出局部修改要求，生成真实候选；先拒绝一次，确认版本数不增加、原稿不变。
3. 再生成并接受一次；保存后刷新重新打开，确认目标文字保留，旁边标记和未选页面不变。
4. 转入 Docs 独立副本；手工修改另一处内容并保存，确认 Studio 原稿未被反向覆盖。
5. 点击当前候选的真实 HTML 下载；取得磁盘文件，记录绝对路径、字节数、SHA-256。仅出现下载链接或事件超时不通过。
6. 通过产品文件导入入口重新导入该磁盘文件；重新保存、刷新，确认 AI 修改与手工修改均保留、页数正确，旧 Docs 副本仍在。
7. 比较导出文件与导入后可再导出的 HTML，按产品既有导出契约核对逐字一致；若有明确的合法规范化，单列差异及依据，不以截图代替源码对比。

**必需证据**：两场景操作记录、真实下载文件及哈希、重导入文档身份、刷新后内容、源码对比、原稿/副本隔离结果。截图需避免个人数据与凭证。

若 IAB 当前下载仍失败，记录具体失败和未完成步骤。可以单列受支持浏览器的真实结果，但不能将其写成 IAB 已通过；不得绕过明确的安全策略。

## A2：异常、冲突与恢复

**当前状态：本机关键路径已有记录；最终候选需定向复核。生产恢复不在已验范围。**

| 任务 | 操作 | 通过标准 |
|---|---|---|
| 取消与晚到结果 | 生成中取消，随后等待模型结束 | 状态取消，版本不增加；晚到结果不可覆盖 |
| 页面恢复 | 生成后关闭/刷新，再打开同任务查询 | 同一任务恢复候选，不重新调用模型；确认才产生版本 |
| 服务重启 | 在隔离开发数据目录制造运行中任务后重启 | 标为 interrupted，解释中断；不声称续跑、不自动消耗模型 |
| 旧版本候选 | 生成后在另一窗口保存新版本，再恢复/应用旧候选 | 拒绝覆盖新版本，用户输入/候选可查看或另存 |
| 幂等 | 重试同 ID 同请求，再用同 ID 不同请求 | 前者不重复调用，后者明确冲突 |
| 错误与资源释放 | 模拟超时、断连、失败响应，再发正常任务 | 错误脱敏、并发槽释放；正常后续任务可完成 |
| 未应用输入 | 填写要求或属性后切换/离开 | 提醒并允许返回；不会静默丢输入 |
| 恢复记录放弃 | 有手工要求时放弃失效记录 | 只移除恢复记录，不清空手工要求 |

**必需证据**：最终候选对应自动测试结果；至少取消、刷新恢复、跨窗口冲突的浏览器记录。用计数/任务 ID 等最小日志证明未重复调用，不收集完整用户源码、要求或密钥。

## A3：回归与变更边界

**当前状态：历史验证可作基线，当前工作区未形成完整可发布范围。**

- 先按文件列出本轮包含/不包含的变更；阅读每个拟发布 diff，包含新文件、依赖锁定、环境开关、同源边界。既有未提交内容保留，不 reset、不批量纳入。
- 固定候选后运行 `npm run typecheck`、相关任务/源码修改/导入/存储测试；运行全量 `npm test` 与 `npm run build:domain`，记录实际命令、退出状态、测试数量与 bundle 结果，不能复制历史数字。
- 复核长文档与演示编辑：选择对象、输入法、未应用输入、撤销/重做、保存、导出、版本恢复；两模式间切换不丢内容。
- 复核页面/格式侧栏折叠恢复、图层操作、位置尺寸应用取消；隐藏控件不占焦点，禁用状态不允许绕过。
- 验证 Agent 关闭时基础 Studio/Docs 可工作；未配置服务端凭据时给出可理解状态，生产产物不含密钥或开发调试日志。
- 审查精确源码修改范围：局部文字只改授权目标；文件导出保留用户原始内容；材料不因改写被当作指令执行。

**通过标准**：范围清单与候选构建一一对应；必需测试与回归全部有当前证据。某项不通过须标为阻断或明确移出发布范围，不能只记录“整体正常”。

## A4：部署前与发布后

**当前状态：Agent 公网发布阻断；只完成本机开发能力。**

当前 Vite `/jobs/*` 开发中间件不是生产 API，静态构建上线不代表 Agent 上线。若本次只发布编辑器 UI，发布范围必须明确排除 Agent，验证生产开关关闭。

公开 Agent 前必须另行完成：

- 生产项目/任务所有权及鉴权；查询、取消、恢复不能越权。MCP/网页调用共用权限边界。
- 生产任务数据库、Worker 租约、幂等和重启策略；明确候选保留期、删除方式、备份恢复，不能复用开发文件目录作为多租户架构。
- 服务端凭据注入、请求大小与超时、免费使用资源限额、错误脱敏、取消和观测；不能把密钥放入浏览器配置。
- 针对实际发布包做生产配置验证、HTTPS/同源检查、健康检查、静态资产哈希与 API 契约验证。
- 准备当前版本与上一版本身份、激活步骤、回滚命令及兼容性说明；数据库变更单列，不假定静态回滚可回滚数据。
- 明确执行者及本次发布授权范围；执行前确认没有混入未验变更。

发布后：在公网实际走一份合成样本的创建、候选、确认、保存刷新和导出路径；另验证免费资源错误与取消。记录公共 URL、发布身份、时间和结果。健康 200、资源哈希或静态入口出现均不能单独证明 Agent 可用。

**放行规则**：A1–A3 当前候选通过，且 A4 对应实际发布范围全部满足，才能记为发布完成。当前本文件不作放行结论。
