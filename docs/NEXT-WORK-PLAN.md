3. 检查损坏文件、尺寸超限和解码失败提示；超时迟到资源释放由确定性回归测试验证，不声称在真实浏览器复现解码挂起。

交付物：资源验收矩阵、可复用样本、一个公网发布版本。发布成功与资源全矩阵通过分别记录，不因部署成功关闭未验收项目。
