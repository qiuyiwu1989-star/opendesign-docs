# Studio Agent 第一轮实现与开发队列

2026-09-27。企业提案与课程并重，首阶段免费。

## 本轮交付

- 服务端 Ark Responses 适配器：原生 fetch，指定 DeepSeek 模型；超时、取消、错误脱敏。
- 一个受范围约束的 propose_text 工具：只生成当前文字的候选。
- 复用现有 proposeText/applyProposal：输入长度限制、源码精确保留、版本冲突检查。
- Studio 本地开发入口：提出要求、生成候选、预览、确认并沿用本机版本保存。
- 本机同源开发接口：单任务并发限制、请求大小限制；密钥只在服务端。

这一轮是单次工具调用形成候选，没有完整 Agent 多轮工具循环、SSE、材料解析、后台恢复或公网服务。

## 启动

通过安全的本机环境注入 ARK_API_KEY（不要写入提交或 VITE_ 变量）。

```sh
VITE_STUDIO_AGENT_ENABLED=true npm run dev
```

进入 Studio，创建结构草稿，选择一处文字，输入要求并生成候选。模型仅接收选区内容及修改要求；完整源码只传到本机服务用于校验。确认后沿用现有 IndexedDB 保存和并发检查。

CLI 可执行：`node --import tsx services/studio-agent/cli.ts`，stdin 为 JSON：version（id、label、source）、targetId、instruction。stdout 为未应用候选；用户内容可能包含隐私，勿直接收集完整日志。

生产构建不显示 AI 入口，Vite 开发中间件不属于生产部署方案。

## 后续里程碑

1. 浏览器验收：企业/课程各一份，生成候选→拒绝/接受→保存→刷新→导出→重新导入；同时验证取消和跨窗口保存冲突。
2. 真正任务运行层：项目所有权、PostgreSQL 任务/事件/候选、Worker 租约与幂等、恢复/取消、用量记录；审计旧 Agent OS 契约后复用。
3. 材料理解与创作：来源检索、Library 参考、大纲与方向、三页生成、确定性布局 QA；补全 Function Calling 结果回传与有限多轮执行。
4. SSE 进度、受控评审子任务、MCP 统一权限和项目服务；完成真实用户回路后公开部署。

旧 studio-agent-os README 明确是纯领域契约包，不含模型调用、网络、持久化与发布；不可把包存在当成任务恢复已实现。

已通过：
- 企业提案：生成真实 AI 标题候选；拒绝不产生版本；接受后第 2 版保存，刷新再打开标题保留；恢复初稿创建第 3 版。

- 离开保护：仅输入 AI 要求时关闭 Studio，显示未保存输入提醒。
- 课程：模型将学习目标改为可观察任务，接受后保存；转为 Docs 独立副本，5 页可见；刷新后改写内容保留。
- 并发：两个浏览器标签读取相同课程版本；第一标签保存成功，第二标签旧版本写入被拒绝，候选保留。

修复：
- AI 指令输入纳入离开提示；提供清空按钮；有未处理指令时阻止转入 Docs。
- 取消请求显示正常状态，不再显示原生异常。
- 请求体按字节收集后统一 UTF-8 解码，避免中文跨网络块损坏。

## 第三轮：可恢复的本地生成任务（2026-09-27）

### 已实现
- 异步任务创建、查询、取消；状态 running / candidate / failed / cancelled / interrupted。
- 文件原子写入，目录 0700、文件 0600；本机 `.local/studio-agent/` 已 gitignore。候选包含用于版本校验的原始 HTML，不存 API Key、原始模型错误或修改指令。
- 客户端请求前保存 UUID，服务端用请求哈希校验幂等：相同任务不重复调用模型，不同请求复用 ID 会被拒绝。
- 刷新后手动恢复查询候选；版本变化时拒绝恢复应用。取消后迟到结果不覆盖取消状态。
- 服务重启时，把未结束任务标记 interrupted；不会假装继续执行或自动重新消耗模型。
- 失效记录可以放弃；放弃恢复记录不会清空用户手动输入。

### 已验证
- 浏览器真实模型：生成“核查来源，用证据表达”候选→离开 Studio→刷新→重新进入→恢复生成结果→确认→第 4 版保存。恢复查询未重新调用模型。
- 浏览器取消生成后未增加版本。
- 企业提案/课程自动往返：手改与 AI 修改→保存重读→HTML Blob→File→真实文件导入验证→独立文档保存重读。源码逐字一致，原文档和其他页面保留。
- 任务持久化、恢复、取消晚到结果、幂等重试和 HTTP 同源边界均有自动测试。

### 明确限制与下一步
这是单进程、本机开发任务管理，最多保留 100 条记录，不是生产 Worker/多租户服务。当前服务重启仅标记中断，不能续跑模型步骤。旧同步 `/edit` 接口保留兼容，Studio 已采用 `/jobs/*`。
浏览器磁盘下载仍未拿到完成证据；不能用自动 Blob/File 测试替代下载验收。
后续优先：生产项目所有权与数据库任务存储、Worker 租约、SSE 进度、材料/大纲工具与有限多轮执行，再做公网发布。

本轮最终验证：10 个相关测试文件、76 项测试通过；TypeScript、生产构建和 bundle 检查通过。客户端预分配 ID 的最终版本已再次完成真实模型生成，拒绝候选后保持第 4 版不变。
