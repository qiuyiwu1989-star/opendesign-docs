网站：浏览器 SDK

<script src="https://doc.opendesign.cc/sdk/opendesign.js"></script>
<button id="edit">在 Docs 中编辑</button>
<script>
// HTML 提前准备；直接在点击回调中调用，保留浏览器弹窗授权。
edit.onclick = async () => {
  const result = await OpenDesign.open(

  );
  // result.ok === true 才表示用户已确认且本地保存成功。

</script>

也提供 ES module。来源页必须使用 HTTP(S)，并允许保留跨窗口 opener；被浏览器拦截时提供下载 HTML 的备用入口。

AI 工具：MCP

在支持远程 Streamable HTTP 的客户端中连接 https://doc.opendesign.cc/connect/mcp，调用 opendesign_create_document_handoff：

{ "name": "报告.html", "html": "<h1>报告</h1>" }

工具返回 open_url 和 expires_at。用户点击链接，再确认导入 Docs。服务已公开，无需 API Key。ready 表示链接准备就绪，用户确认后才算导入成功。

服务端：REST API

提交 HTML 源码，获取临时交接链接。浏览器网站使用上面的 SDK；REST 面向服务端，跨站浏览器请求不会被接受。

curl https://doc.opendesign.cc/connect/api/handoffs \
  -H 'Content-Type: application/json' \
  --data '{"name":"hello.html","html":"<!doctype html><h1>Hello OpenDesign</h1>"}'

成功返回 HTTP 201，包含 status、open_url、expires_at。展示返回的链接，由用户打开；不要将临时链接放入公开日志。

通用连接参数

{
  "url": "https://doc.opendesign.cc/connect/mcp",
  "transport": "Streamable HTTP",
  "authentication": "none"
}

以上是连接参数说明，各 AI 客户端配置格式有所不同。已验证 initialize、tools/list、tools/call；不支持旧 SSE 或后台长期订阅。

REST OpenAPI 规范 · AI 接入说明 · 服务健康状态

免费试运行额度

每个来源 IP 每分钟 30 次 POST（包括 MCP 初始化、工具调用和读取）；全服务最多同时保存 100 份 / 60 MiB 内容。429 表示请求过多，503 表示容量或并发已满。超时后请先检查是否已导入，避免重复创建。

接入范围

  • 每份 HTML 最多 5 MiB；推荐内联样式和图片、静态 SVG。
  • 不自动抓取第三方网址，不执行导入 HTML 的脚本。动态应用及外部资源不能保证原样显示。
  • MCP 临时内容保留 15 分钟，导入成功后清除；持有链接的人可读取，服务重启会提前失效。
  • 免费版先验证编辑与交付。团队协作、长期云存储、更高额度可作为后续高级功能，暂未开放。
