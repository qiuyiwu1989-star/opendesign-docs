# 场景样板与设计总监输出约定

2026-09-19。此轮为人工编写的合成样板，不是模型运行结果；尚未做教师/企业目标用户评审。

## 共用简报

1. 使用者、受众、使用场合与要达成的行动。
2. 已有材料、事实来源、假设、缺失材料。
3. 两到三个方向：叙事结构、视觉规则、适用条件与取舍。
4. 推荐方向与理由；逐页大纲与交付形式。
5. 人工已改内容、允许修改范围、基线版本。
6. 验收：内容正确、版式可读、修改保留、版本恢复、实际交付。

这是一份后续 Studio 的输入/输出约定草案，不代表设计总监 AI 已实现。

## 教师课程

- 场景：七年级，40 分钟课堂。目标是区分主张与证据，练习来源、交叉验证与不确定性。
- 方向 A（采用）：从虚构校园消息出发，判断→方法→材料对照→反思。留白、双栏对照和三个问题服务投影阅读。
- 方向 B：概念手册，先定义再给案例，适合课后复习，但课堂参与感较弱。
- 方向 C：小组辩论，适合已有基础的学生，需要更多主持时间；容易让观点竞争盖过查证过程。
- 交付：9 页 1280×720 HTML 演示、独立活动单。正文 25–32 px；标题 46–62 px；无需网络字体或图片。
- 材料边界：校园消息、通知和老师答复均明确标注虚构；未使用学生个人信息。真实班级阅读能力与教学效果待教师反馈。
- 活动单有 A4 打印样式，但实际纸张/PDF 分页另验收，不以 CSS 声明代表打印通过。

## 企业提案

- 场景：15 分钟管理层汇报，申请四周小范围流程试点。
- 方向 A（采用）：问题→证据缺口→现状→方案比较→推荐→时间线→预算风险→决策。表格支持取舍，四列时间线明确阶段。
- 方向 B：长文备忘录，适合异步审阅，可在 Docs 长文视图阅读，但口头汇报需另做摘要。
- 方向 C：数据仪表板，适合已有可靠基线的阶段；当前没有真实数据，不采用。
- 交付：8 页 HTML 演示。预算说明保持可编辑，未知投入与收益明确标为待确认。
- 材料边界：访谈为合成材料、四周为建议时间线、比较项为方案假设；不虚构收益、客户背书和实测指标。

## 下一步
