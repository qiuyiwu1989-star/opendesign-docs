# 042 免费场景样板

## 用户问题

已有 HTML 用户可导入，但从零开始的教师和企业用户缺少可直接修改的起点。

## 实现

- 文档库增加“从场景样板开始”，可创建教师课程（9 页＋独立活动单）或企业提案（8 页）。
- 创建新文档副本，走已有存储、切换确认与版本流程；不覆盖已有文档。
- 按需加载样板模块；加载失败给出重试提示，重复点击有锁。
- 内容完全自包含，无远程资源；明确标注合成材料与待确认数据。免费，无账号/支付门槛。
- 原始 HTML 在 examples/scenarios/；设计取舍在 docs/SCENARIO-DESIGN-NOTES.md。

## 验收

本轮记录见 docs/ACCEPTANCE.md。目标用户评审、真实投影与纸张打印另行验收；样板不能被称为 AI 生成能力已上线。
